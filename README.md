# AI Language Lab — 它怎么学会接话？

给它几句话，看一个小模型怎样从乱猜到慢慢学会接话。一个零依赖、零构建的纯静态网页，在浏览器里真实训练一个「看一个字、猜下一个字」的字符级小模型。

## 主要功能

- 输入或选择预设语料（打招呼 / 小诗 / 咖啡馆），模型即刻从随机权重开始
- 逐次「开始练习」或一键「练 200 次」，实时观察损失曲线下降
- 可视化转移矩阵与条件概率条，点击矩阵查看任意字符后的预测
- 调节「说话的自由度」（temperature）控制生成句子的保守与发散
- 「再说一句」：模型按当前学习程度现场生成一句话

## 界面风格

页面采用 `ydchen-portfolio` 的视觉语言：暖米白背景、陶土橙强调色、深色细线网格、衬线标题与系统无衬线正文。实验区在宽屏以三栏等高卡片加全宽生成结果呈现，自动在中等宽度折为两栏、手机折为单栏；模型交互结构保持不变。

本项目为普通项目类。页眉桌面 72px、手机（≤640px）64px；方章 48×48px / 40×40px，标题衬线 18px/400/1.3、手机 16px，副标题无衬线 12px/400/1.4；标志与标题间距 12px，标题与副标题间距 2px。

页眉内容区最大宽度 1280px（含两侧各 16px 内边距），整体居中；品牌和标题靠左，操作区靠右，窄屏换行后仍保持该对齐。品牌页眉在文档顶部正常排布，随页面滚走，不固定或吸顶；表格内部表头、侧边工具和手机底部导航可按功能保留。

正文采用统一系统无衬线字体，默认 16px / 1.6；标题采用 Georgia、Times New Roman、Songti SC、STSong 衬线族。数字与代码可使用 SFMono-Regular、Consolas、Liberation Mono、Microsoft YaHei 等宽族。按钮和输入通常 15px，辅助文字 12–14px，密集科学数据允许有理由的局部调整。页面底色 #f3eee5、正文 #24221f、赤陶强调 #a94f31，柔和底色上的强调文字 #823a25；科学分类色、热图、作品主题与状态色保留必要区分度。

## 数据与隐私

全部计算在浏览器本地完成，不上传任何数据；不写入 `localStorage`、不使用 Cookie、无任何用户数据采集。

## 本地运行

项目无任何构建步骤，直接用浏览器打开 `index.html` 即可。

如需本地静态预览：

```bash
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

## 部署

纯静态页面，可部署到任意静态托管。例如 Cloudflare Pages（GitHub 集成）：

```text
Production branch: main
Build command: （留空，无需构建）
Build output directory: /
```

## 维护与兼容

示例语料按钮同步报告选中状态，转移概率矩阵沿用主题强调色；清理重复样式后保持原有暖米白与赤陶色视觉。

统一页眉与字号，移除被后续同选择器覆盖的旧属性；保留词元矩阵的数值颜色语义。浏览器已验证重新载入语料、单步与 200 次训练、生成句子。

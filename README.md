# AI Language Lab — 它怎么学会接话？

给它几句话，看一个小模型怎样从乱猜到慢慢学会接话。一个零依赖、零构建的纯静态网页，在浏览器里真实训练一个「看一个字、猜下一个字」的字符级小模型。

## 主要功能

- 输入或选择预设语料（打招呼 / 小诗 / 咖啡馆），模型即刻从随机权重开始
- 逐次「开始练习」或一键「练 200 次」，实时观察损失曲线下降
- 可视化转移矩阵与条件概率条，点击矩阵查看任意字符后的预测
- 调节「说话的自由度」（temperature）控制生成句子的保守与发散
- 「再说一句」：模型按当前学习程度现场生成一句话

## 界面风格

页面采用 `ydchen-portfolio` 的视觉语言：暖米白背景、陶土橙强调色、深色细线网格、衬线标题与系统无衬线正文。实验区在宽屏以三栏等高卡片加全宽生成结果呈现，自动在中等宽度折为两栏、手机折为单栏；模型交互结构保持不变。

## 数据与隐私

全部计算在浏览器本地完成，不上传任何数据；不写入 `localStorage`、不使用 Cookie、无任何用户数据采集。

## 本地运行

项目无任何构建步骤，直接用浏览器打开 `index.html` 即可。

如需本地静态预览：

```bash
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

## 部署

纯静态页面，可部署到任意静态托管。例如 Cloudflare Pages（GitHub 集成）：

```text
Production branch: main
Build command: （留空，无需构建）
Build output directory: /
```

## 跨项目视觉与回归基准（2026-09-13）

本项目归类为 **普通项目**。72px / 64px 页眉，48px / 40px 方章，18px / 16px 衬线标题，12px 无衬线副标题。 正文采用统一系统无衬线字体、默认 16px / 1.6；标题使用衬线层级，数字与代码可使用统一等宽族。辅助文字通常为 12–14px，密集科学数据可按实际场景调整。主界面延续米白与赤陶 #a94f31，柔和色块上的文字用更深色保证可读性。

统一页眉与字号，移除被后续同选择器覆盖的旧属性；保留词元矩阵的数值颜色语义。浏览器已验证重新载入语料、单步与 200 次训练、生成句子。

当前检查命令：

```bash
node --test tests/static-smoke.test.mjs
```

## 页眉水平对齐

页眉内容区最大宽度统一为 1280px（含两侧各 16px 留白），整体居中；标志和标题靠左，操作区靠右，窄屏可换行。保持本类字体、字号与标志尺寸，页眉随文档滚走。本约定替代旧的 1440px 页眉和随视口变化的横向留白。

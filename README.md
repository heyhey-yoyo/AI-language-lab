# AI Language Lab — 它怎么学会接话？

给它几句话，看一个小模型怎样从乱猜到慢慢学会接话。一个零依赖、零构建的纯静态网页，在浏览器里真实训练一个"看一个字、猜下一个字"的字符级小模型。

## 主要功能

- 输入或选择预设语料（打招呼 / 小诗 / 咖啡馆），模型即刻从随机权重开始
- 逐次「开始练习」或一键「练 200 次」，实时观察损失曲线下降
- 可视化转移矩阵与条件概率条，点击矩阵查看任意字符后的预测
- 调节"说话的自由度"（temperature）控制生成句子的保守与发散
- 「再说一句」：模型按当前学习程度现场生成一句话

## 视觉风格

页面采用 `ydchen-portfolio` 的视觉语言：暖米白背景、陶土橙强调色、深色细线网格、衬线标题与系统无衬线正文。实验面板和模型交互结构保持不变，只调整了页面层级、留白、边框和响应式呈现。

正文保持 16px 基线，实验控件与图表标签不小于 12px；桌面和手机端均需检查文字辨识度及页面整体横向溢出。

## 本地运行

项目无任何构建步骤，直接用浏览器打开 `index.html` 即可。

如需本地静态预览：

```bash
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

## 部署

纯静态页面，可部署到任意静态托管。例如 Cloudflare Pages（GitHub 集成）：

```text
Production branch: main
Build command: （留空，无需构建）
Build output directory: /
```

## 技术栈

| 技术 | 说明 |
| --- | --- |
| HTML / CSS / JavaScript | 三文件静态网页（`index.html` + `styles.css` + `app.js`），零依赖、零构建 |
| 浏览器端训练 | 字符级 softmax 语言模型（SGD 训练，无需后端） |

## 数据与隐私

全部计算在浏览器本地完成，不上传任何数据；不写入 `localStorage`、不使用 Cookie、无任何用户数据采集。

## 项目结构

```text
index.html     页面结构（HTML）
styles.css     全部样式（原单文件内 <style> 抽取）
app.js         模型与交互逻辑（原单文件内 <script> 抽取）
.gitignore     忽略 GitHub CLI 本地配置（.gh-config/）
```

## 维护提示

- 改样式 → 编辑 `styles.css`
- 改交互/模型逻辑 → 编辑 `app.js`
- 改页面结构 → 编辑 `index.html`
- 拆分时已清理原单文件中 ChatGPT 导出的追踪拦截/哨兵守卫脚本与 `/Static/`、`/Web/`、`/_ooa/` 外部残留引用（静态托管上会 404，且代码并不依赖它们）
